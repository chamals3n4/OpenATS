# What is OpenATS?

OpenATS is an open-source applicant tracking system for organizations that want to run hiring in one clear, shared workspace. It replaces disconnected spreadsheets, inboxes, and point tools with a process that follows a candidate from an open role through interview and final decision.

## Who it is for

OpenATS is for internal hiring teams, recruiting teams, and organizations building their own recruitment platform. It can be used as a ready-to-run applicant tracking system or as a foundation that your engineering team can extend to fit an existing process.

## How it helps

For every open role, OpenATS gives the hiring team a structured pipeline and a single source of truth. A candidate record keeps the resume, contact information, interview feedback, notes, activity, and decision together. Hiring Managers can see progress across a role, while Interviewers receive the context they need to evaluate candidates.

The platform also supports career pages for applications, configurable hiring teams, role-based access, interview coordination, and background AI resume parsing. AI work runs separately from the normal web application, so a slow analysis request does not interrupt candidate-facing flows.

## What you control

OpenATS is built with standard open-source technology: Next.js, Express, PostgreSQL, Redis, BullMQ, and WSO2 Identity Platform. You control the code, database, storage configuration, authentication setup, and integrations rather than adapting your process to a closed vendor system.
